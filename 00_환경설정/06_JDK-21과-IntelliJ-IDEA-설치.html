0장. 환경설정 — 과정 전체 개발 도구 설치

JDK 21(Eclipse Temurin)과 IntelliJ IDEA 설치

준비시간40분개념 지도06 JDK · IntelliJ

한 줄 요약

10장부터 Spring 서버를 Java로 만듭니다. Java 코드를 실행하려면 JDK가, 편하게 쓰고 실행하려면 IntelliJ IDEA가 필요합니다. JDK는 무료 배포판인 Eclipse Temurin 21(LTS)을 설치하고, 설치 중 JAVA_HOME 설정 칸 하나를 켭니다. IntelliJ IDEA는 2025.3부터 무료판과 유료판이 하나의 프로그램으로 합쳐졌습니다. 그대로 설치하면 이 과정에 필요한 기능은 모두 무료로 씁니다. 마지막으로 IntelliJ가 JDK 21을 알아보는지 확인합니다.

설치 시점: 10장 직전.

1. JDK 21 — Eclipse Temurin

1-1. 받기

  1. adoptium.net의 Temurin 내려받기 화면을 엽니다.
  2. 고르는 칸을 Operating System: Windows, Architecture: x64, Package Type: JDK, Version: 21 - LTS로 맞춥니다.
  3. 목록에서 .msi 파일을 받습니다. 이름이 OpenJDK21U-jdk_x64_windows_hotspot_21.0.….msi 같은 모양입니다.
헷갈리기 쉬운 것 고를 것
JDK와 JRE JDK. JRE는 실행만 하고 컴파일러가 없다
21과 더 높은 버전(25 등) 21. 이 과정의 Spring Boot 4.1 · Gradle 설정은 Java 21로 맞췄다(10장 build.gradle의 JavaLanguageVersion.of(21))
.msi와 .zip .msi. 설치 프로그램이 PATH · JAVA_HOME까지 설정해 준다

1-2. 설치 — JAVA_HOME 칸 하나만 켠다

받은 .msi를 더블클릭합니다. 사용권에 동의하고 Next를 누르면 Custom Setup 화면이 나옵니다. 여기서 한 칸만 바꿉니다.

항목 (화면 글자) 기본값 고를 것 하는 일
Add to PATH 설치 그대로 java 명령을 어디서나 칠 수 있다
Associate .jar 설치 그대로 .jar 파일을 더블클릭하면 Java로 연다
Set JAVA_HOME variable 설치 안 함 (X 표시) "Will be installed on local hard drive"로 바꾼다 JAVA_HOME에 JDK 위치를 적는다. Gradle 같은 도구가 이것으로 Java를 찾는다
JavaSoft (Oracle) registry keys 설치 안 함 그대로 이 과정에서 필요 없다

항목 이름 왼쪽의 아이콘을 누르면 메뉴가 열립니다. Set JAVA_HOME variable 왼쪽 아이콘을 눌러 Will be installed on local hard drive를 고르면 X 표시가 사라집니다. 그다음 Next → Install → 예 → Finish입니다.

출처: Adoptium — Windows MSI 설치 안내(설치 항목 FeatureJavaHome은 기본으로 꺼져 있음)

1-3. 확인

설치 전 열려 있던 터미널은 바뀐 PATH를 모르므로, VS Code를 다시 켜고 새 터미널에서 칩니다.

java -version

openjdk version "21.0.12.1" 2026-08-18 LTS
OpenJDK Runtime Environment Temurin-21.0.12.1+1 (build 21.0.12.1+1-LTS)
OpenJDK 64-Bit Server VM Temurin-21.0.12.1+1 (build 21.0.12.1+1-LTS, mixed mode, sharing)

첫 줄에 "21., 둘째 줄에 Temurin이 보이면 됩니다. 뒤 숫자와 날짜는 받은 때에 따라 다릅니다.

JAVA_HOME도 확인합니다(PowerShell에서 환경 변수를 읽는 모양입니다).

$env:JAVA_HOME

C:\Program Files\Eclipse Adoptium\jdk-21.…-hotspot 같은 경로가 나오면 됩니다. 아무것도 안 나오면 1-2의 칸을 빠뜨린 것입니다. .msi를 다시 실행해 Change(바꾸기)를 고르고 그 칸을 켭니다.

보이는 것 원인 할 일
'java' 용어가 … 인식되지 않습니다 터미널이 설치 전 것 VS Code를 다시 켠다. 그래도 같으면 컴퓨터를 다시 시작한다
java version "1.8.…", "17.…" 등 다른 버전 예전에 설치한 Java가 PATH에서 먼저 잡힌다 설정 → 앱 → 설치된 앱에서 예전 Java를 지우고, 터미널을 새로 열어 다시 확인한다

2. IntelliJ IDEA

2-1. 어떤 IntelliJ를 받나

예전 (2025.2까지) 지금 (2025.3부터)
Community Edition(무료)과 Ultimate(유료)를 따로 받았다 IntelliJ IDEA 하나만 받는다. 구독이 없어도 상업용 · 비상업용 모두 무료로 쓰고, 일부 기능만 구독이 필요하다
이 과정에서 쓰는 것 구독 없이
Java 코드 쓰기 · 실행 · 디버깅, Gradle 프로젝트 열기, Terminal, Git 된다
Spring 설정 파일 색칠 · 새 Spring 프로젝트 만들기 마법사 된다 (이 과정은 start.spring.io에서 프로젝트를 받으므로 마법사는 쓰지 않는다)
.http 파일 옆 ▶ 버튼 (HTTP Client) 구독이 필요하다. 10장 07절의 안내대로 같은 .http 파일을 VS Code REST Client(9장)로 보낸다
DB 표 안의 데이터 보기 · SQL 실행 구독이 필요하다. 이 과정은 pgAdmin(08절)으로 한다

출처: JetBrains 블로그 — IntelliJ IDEA 통합 배포 계획(2025-07)

2-2. 받기와 설치

  1. jetbrains.com/idea/download에서 Windows를 고르고 .exe를 받습니다.
  2. 받은 .exe를 더블클릭하고 Next를 누릅니다. 설치 위치는 기본값 그대로 Next.
  3. Installation Options 화면에서 아래처럼 체크하고 Next → Install을 누릅니다.
칸 고를 것 이유
Create Desktop Shortcut 원하는 대로 —
Update PATH Variable (Add "bin" folder to the PATH) 비워 둔다 터미널에서 IntelliJ를 여는 명령. 이 과정에서 쓰지 않는다
Update Context Menu (Add "Open Folder as Project") 체크 폴더를 오른쪽 클릭해 IntelliJ 프로젝트로 연다
Create Associations (.java 등) 비워 둔다 .java 파일을 더블클릭할 일이 거의 없다

설치가 끝나면 Finish를 누릅니다. 다시 시작하라는 칸이 나오면 그대로 따릅니다.

출처: JetBrains — IntelliJ IDEA 설치 안내(Windows 독립 설치)

JetBrains Toolbox App: JetBrains는 여러 제품을 설치하고 업데이트하는 Toolbox App을 권합니다. 이 과정은 IntelliJ 하나만 쓰므로 위처럼 바로 설치하는 방법으로 충분합니다. 집에서 다른 JetBrains 제품도 쓴다면 Toolbox로 설치해도 됩니다.

2-3. 처음 켜기

  1. 시작 메뉴에서 IntelliJ IDEA를 엽니다.
  2. 사용권 동의 · 사용 통계 보내기(보내지 않아도 된다) 화면을 지납니다. 예전 설정을 가져올지 물으면 Do not import settings 또는 Skip을 고릅니다.
  3. Welcome to IntelliJ IDEA 창(가운데에 New Project · Open 버튼)이 보이면 설치 끝입니다.

3. IntelliJ가 JDK 21을 알아보나

10장 03절에서 처음 프로젝트를 만들 때 JDK 목록에 21이 있어야 합니다. 지금 미리 확인합니다.

  1. Welcome 창에서 New Project를 누릅니다.
  2. 왼쪽에서 Java를 고르고, 가운데 JDK 칸의 목록을 엽니다.
  3. 21 Eclipse Temurin version 21.0.…(또는 temurin-21) 같은 줄이 보이면 됩니다. 확인만 하고 창을 취소(Cancel)로 닫습니다. 프로젝트는 10장에서 만듭니다.
보이는 것 할 일
목록에 21이 있다 끝
목록에 21이 없다 같은 목록의 Add JDK from disk…를 누르고 C:\Program Files\Eclipse Adoptium\jdk-21… 폴더를 고른다
디스크에도 없다 같은 목록의 Download JDK…에서 Version 21, Vendor Eclipse Temurin을 고르면 IntelliJ가 받아 준다. 그래도 터미널의 java -version을 위해 1절을 다시 한다

핵심 정리

  • JDK는 adoptium.net에서 Temurin 21, Windows x64, JDK, .msi를 받는다. 설치 중 Set JAVA_HOME variable만 켠다(기본은 꺼져 있다).
  • 새 터미널에서 java -version이 "21. · Temurin을, $env:JAVA_HOME이 JDK 경로를 보여 주면 된다.
  • IntelliJ IDEA는 2025.3부터 하나로 합쳐졌다. 구독 없이 이 과정에 필요한 기능을 쓰고, HTTP Client는 VS Code REST Client로, DB 데이터 보기는 pgAdmin으로 대신한다.
  • 설치 옵션은 "Open Folder as Project"만 켠다.
  • New Project의 JDK 목록에 21이 보이는지 확인한다. 없으면 Add JDK from disk.

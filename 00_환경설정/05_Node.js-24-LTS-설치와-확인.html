0장. 환경설정 — 과정 전체 개발 도구 설치

Node.js 24 LTS 설치와 node -v · npm -v 확인

준비시간20분개념 지도05 Node.js

한 줄 요약

Node.js는 브라우저 밖에서 JavaScript를 실행하는 프로그램이고, 설치하면 남의 코드를 받아 오는 npm이 함께 설치됩니다. 5장에서 npm install, 8장에서 React 프로젝트(Vite), 9 · 12장에서 서버를 만들 때 씁니다. 이 과정은 Node.js 24 LTS를 씁니다. 공식 사이트에서 .msi 설치 프로그램을 받아 기본값으로 설치하고, VS Code 터미널에서 node -v · npm -v로 확인합니다.

설치 시점: 2장 첫 수업 전.

1. 어떤 버전을 받나

nodejs.org의 다운로드 화면에는 버전이 여럿 보입니다. 아래를 지킵니다.

고를 것 값
버전 v24.x (LTS). 교안을 쓸 때는 24.22.1이었다. 더 높은 버전(26 등)이 보이거나 그것에 LTS가 붙어 있어도 24를 고른다. 다운로드 화면의 버전 고르는 칸에서 v24를 찾는다
운영 체제 · CPU Windows, x64 (대부분의 노트북이 x64다. 설정 → 시스템 → 정보의 시스템 종류가 ARM64면 같은 페이지의 ARM64 설치 파일을 받는다)
파일 종류 Windows Installer (.msi)

받은 파일 이름은 node-v24.22.1-x64.msi 같은 모양입니다.

왜 24인가: 짝수 번호 버전은 나온 지 반년쯤 뒤 LTS(오래 고쳐 주는 버전)가 되고, 몇 년 동안 보안 수정을 받습니다. 이 과정의 코드(9장 .ts 파일 바로 실행, Express 5, Next.js 16)는 모두 Node.js 24로 확인했습니다. 교안을 쓸 때 Node.js 26도 나와 있었지만 아직 LTS가 아니었고, 26이 LTS가 되더라도 24는 2028년 4월까지 보안 수정을 받습니다. 과정 중에는 모두 같은 24를 씁니다.

출처: Node.js — 배포 목록(index.json), Node.js — Releases

2. 설치

받은 .msi를 더블클릭하고 아래처럼 진행합니다. 모두 기본값이고, 한 화면만 확인합니다.

화면 할 일

End-User License Agreement I accept … 체크 → Next

Custom Setup 기본값 그대로 Next. 목록의 Add to PATH가 설치되도록 되어 있어야 node 명령을 어디서나 칠 수 있다

3. 확인 — VS Code 터미널에서

설치가 끝나면 VS Code를 완전히 껐다가 다시 켭니다. 이미 열려 있던 터미널은 설치 전의 PATH(02절 용어)를 들고 있어서 node를 못 찾습니다. VS Code를 다시 켜고 터미널을 새로 열어야 합니다.

VS Code에서 D:\workspace 폴더를 열고, Terminal → New Terminal(Ctrl + `)에 한 줄씩 칩니다.

node -v
npm -v

v24.22.1
11.19.1

첫 줄이 v24.로 시작하면 됩니다. 뒤 숫자는 받은 때에 따라 다릅니다. 둘째 줄은 npm의 버전이고, 숫자가 나오기만 하면 됩니다.

npm -v에서 "이 시스템에서 스크립트를 실행할 수 없으므로 … npm.ps1 파일을 로드할 수 없습니다"가 나오면: VS Code 터미널의 기본 셸인 PowerShell이 스크립트 실행을 막은 것입니다. 같은 터미널에 아래 한 줄을 입력하고, 물으면 Y를 누른 뒤 npm -v를 다시 칩니다. 내 계정에서만 내 컴퓨터에서 만든 스크립트를 허용하는 설정입니다. 8장 03절에도 같은 안내가 있습니다.

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

출처: Microsoft 문서 — about_Execution_Policies

보이는 것 원인 할 일
'node' 용어가 cmdlet, 함수, 스크립트 파일 또는 실행할 수 있는 프로그램 이름으로 인식되지 않습니다 터미널이 설치 전 것이거나, 설치가 끝나지 않았다 VS Code를 껐다 켠다. 그래도 같으면 컴퓨터를 다시 시작한다
v20.…, v22.…처럼 다른 버전 예전에 설치한 Node.js가 남아 있다 설정 → 앱 → 설치된 앱에서 Node.js를 지우고 2절을 다시 한다
npm.ps1 파일을 로드할 수 없습니다 PowerShell 실행 정책 위 상자

핵심 정리

  • nodejs.org에서 v24 LTS, Windows x64, .msi를 받는다. 더 높은 버전이 보여도 LTS 24를 고른다.
  • 설치는 기본값 그대로, Tools for Native Modules 체크 칸만 비워 둔다.
  • 설치 뒤 VS Code를 다시 켜고 새 터미널에서 node -v(v24.로 시작) · npm -v를 확인한다.
  • npm.ps1을 로드할 수 없다는 오류는 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned 한 번으로 푼다.

0장. 환경설정 — 과정 전체 개발 도구 설치

PostgreSQL 17 설치판과 pgAdmin 4

준비시간40분개념 지도08 PostgreSQL · pgAdmin

한 줄 요약

9장부터 메모 · 게시판 데이터를 PostgreSQL이라는 DB에 저장합니다. Windows용 설치 프로그램 하나로 DB 서버, 화면으로 DB를 다루는 pgAdmin 4, 명령 도구가 함께 설치됩니다. 설치 중 정하는 비밀번호와 포트 번호(5432)는 9장 .env와 10장 설정 파일에 그대로 다시 씁니다. 그래서 이 절에서 가장 중요한 일은 비밀번호를 정하고 적어 두기입니다. 마지막으로 pgAdmin에서 서버에 접속해 봅니다.

설치 시점: 9장 직전. 설치 프로그램은 EDB라는 회사가 만들어 배포합니다. 14장부터는 같은 DB를 Docker 컨테이너(postgres:17, 5433번)로도 띄우는데, 이 설치판과 따로 돌며 부딪치지 않습니다(07절 그림).

1. 받기

  1. postgresql.org — Windows installers를 열고 Download the installer를 누릅니다. EDB 내려받기 화면으로 넘어갑니다.
  2. 표에서 PostgreSQL 버전 17.x 줄의 Windows x86-64 칸을 누릅니다.
  3. postgresql-17.…-windows-x64.exe 같은 이름의 파일이 받아집니다.

왜 17인가: 이 과정의 9 · 10장 화면(pgAdmin 왼쪽의 PostgreSQL 17)과 설명이 17 기준이라 17을 받습니다. PostgreSQL은 큰 버전마다 5년 동안 수정 버전을 내므로 17은 과정 내내 충분히 씁니다.

출처: PostgreSQL — Versioning Policy

2. 설치 — 화면 순서

받은 .exe를 더블클릭하고, 사용자 계정 컨트롤 창에서 예를 누릅니다.

비밀번호는 정하자마자 적어 둡니다. 이 비밀번호는 다시 볼 방법이 없고, 9장 .env의 DB_PASSWORD, 10장 .env의 같은 칸에 그대로 씁니다. 잊으면 다시 설치하는 것이 가장 빠릅니다.

  • 영어 소문자와 숫자로만 8자 이상 짓습니다. # · $ · = · 빈칸 같은 기호는 .env 파일에서 다르게 읽힐 수 있어 피합니다.
  • 내 컴퓨터 안에서만 쓰는 연습용 비밀번호입니다. 다른 사이트 비밀번호를 다시 쓰지 않습니다.
  • 메모장 · 노트에 "PostgreSQL postgres 계정 비밀번호"라고 적어 둡니다. 이 메모를 GitHub에 올리지는 않습니다.

Stack Builder는 PostgreSQL에 붙이는 추가 프로그램을 받는 도구입니다. 이 과정에서는 쓰지 않으므로 마지막 화면에서 끕니다. 실수로 켜졌으면 Cancel로 닫으면 됩니다. Command Line Tools에는 터미널에서 SQL을 치는 psql이 들어 있지만, 이 과정은 SQL을 pgAdmin 화면에서 칩니다.

3. 켜져 있나 — Windows 서비스

PostgreSQL은 창이 없는 프로그램입니다. 설치가 끝나면 Windows 서비스로 등록되어, 컴퓨터를 켤 때마다 저절로 켜집니다.

  1. 작업 표시줄 검색 칸에 서비스를 치고 서비스 앱을 엽니다.
  2. 목록에서 postgresql-x64-17을 찾습니다.
  3. 상태가 실행 중이면 됩니다. 아니면 그 줄을 오른쪽 클릭 → 시작을 누릅니다.

10장에서 Connection to localhost:5432 refused가 나오면 여기부터 봅니다.

4. pgAdmin 4로 접속해 보기

  1. 시작 메뉴에서 pgAdmin 4를 엽니다. 처음에는 켜지는 데 10~30초 걸립니다.
  2. 왼쪽 Object Explorer에서 Servers를 펼치고 PostgreSQL 17을 누릅니다.
  3. 비밀번호 창에 2절에서 정한 비밀번호를 넣습니다. Save Password를 체크하면 다음부터 묻지 않습니다. OK.
  4. PostgreSQL 17 아래에 Databases · Login/Group Roles 같은 항목이 펼쳐지고, Databases 안에 postgres가 보이면 접속 성공입니다.

DB와 표를 만드는 일은 9장 09절에서 합니다. 지금은 접속만 확인하고 pgAdmin을 닫습니다.

보이는 것 원인 할 일
password authentication failed for user "postgres" 비밀번호가 틀렸다 적어 둔 비밀번호를 다시 넣는다. 한/영 키, Caps Lock을 확인한다
connection refused · could not connect to server DB 서버가 꺼져 있다 3절에서 서비스를 시작한다
비밀번호가 끝내 기억나지 않는다 — 설정 → 앱 → 설치된 앱에서 PostgreSQL 17을 지우고 다시 설치한다. 지울 때 데이터 폴더(C:\Program Files\PostgreSQL\17\data)가 남으면 탐색기에서 지운 뒤 설치한다
pgAdmin 창이 하얗게만 보인다 아직 켜지는 중 30초쯤 기다린다. 그래도 같으면 pgAdmin을 닫고 다시 연다

pgAdmin 메뉴도 영어로 둡니다. 교안은 Object Explorer, Query Tool, Save Password처럼 영어 이름으로 적습니다. pgAdmin은 File → Preferences → Miscellaneous → User language에서 언어를 바꿀 수 있지만, 그대로 English로 둡니다.

핵심 정리

  • postgresql.org → EDB 설치 프로그램에서 17.x, Windows x86-64를 받는다.
  • 구성 요소는 네 칸 그대로, 포트 5432, Locale 기본값. 마지막 화면의 Stack Builder 체크는 끈다.
  • postgres 계정 비밀번호는 영어 소문자 · 숫자로 짓고 바로 적어 둔다. 9 · 10장 .env의 DB_PASSWORD에 쓴다.
  • 서비스 앱에서 postgresql-x64-17이 실행 중인지 본다.
  • pgAdmin 4 → Servers → PostgreSQL 17 → 비밀번호 → Databases 안에 postgres가 보이면 끝.

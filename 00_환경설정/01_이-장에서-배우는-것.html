0장. 환경설정 — 과정 전체 개발 도구 설치

도구는 한 번에 다 설치하지 않고, 쓰기 직전에 하나씩

준비시간10분개념 지도전체 그림

한 줄 요약

이 과정은 HTML 한 장에서 시작해 React 화면, Node.js · Spring 서버, DB, Docker까지 갑니다. 그만큼 설치할 프로그램도 많습니다. 이 장은 과정 전체에서 쓰는 개발 도구를 한곳에 모은 설치 안내서입니다. 다만 한 번에 다 설치하지 않습니다. 처음에 설치한 도구를 몇 달 동안 안 쓰면 버전이 바뀌고, 설정도 잊어버립니다. 그래서 그 도구를 처음 쓰는 장 바로 전에 해당 절만 따라 합니다. 마지막 09절의 체크리스트로 "다 잘 설치됐나"를 한 번에 확인합니다.

대상은 Windows 11입니다. 작업 폴더는 D:\workspace 하나이고, 모든 장의 프로젝트가 이 아래에 생깁니다. Git과 Git Bash는 1장 03절(사전학습)에서 설치합니다.

1. 전체 그림

절 설치하는 것 언제 처음 쓰는 곳
03절 (설치 전 확인) 파일 확장자 보이기, D:\workspace 만들기 2장 첫 수업 전 2장부터 모든 장
04절 VS Code + 확장 2장 첫 수업 전 2장 05절 첫 HTML 파일

07절 Docker Desktop (WSL 2) 14장 직전 14장 Docker 핵심, 그 뒤 모든 장

09절 (확인) 버전 명령 한 번에, 문제 해결 설치할 때마다 —

절은 순서대로 따라 하지 않습니다. 절은 도구의 종류별로 나누어 놓았고, 실제로 설치하는 시점은 위 표의 "언제" 칸을 따릅니다. 2장 첫 수업 전에는 03 · 04 · 05절만 합니다. 08절(PostgreSQL)은 9장 직전, 06절(JDK · IntelliJ)은 10장 직전, 07절(Docker)은 14장 직전에 합니다. 미리 해 두어도 됩니다. 그때 버전이 바뀌었으면 큰 번호(Node 24, JDK 21, PostgreSQL 17)만 맞추어 받습니다.

3. 나중에 찾아볼 것

필요할 때 찾아볼 것: 명령 한 줄로 설치하는 winget, 여러 Node 버전을 바꿔 쓰는 도구(nvm-windows 등), JetBrains Toolbox App, WSL 2를 따로 쓰는 법(Ubuntu 설치), 환경 변수 PATH · JAVA_HOME 직접 고치기. 필요해지면 각 도구의 공식 문서(Node.js, Adoptium, IntelliJ IDEA, Docker Desktop, PostgreSQL)를 봅니다.

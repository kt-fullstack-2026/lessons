0장. 환경설정 — 과정 전체 개발 도구 설치

용어 정리

준비시간10분개념 지도전체 그림

1. 명령과 경로에 관한 말

용어 뜻 예
터미널 (terminal) 글자로 명령을 쳐서 컴퓨터를 움직이는 창. 이 장에서는 버전을 확인할 때만 쓴다 VS Code 터미널, IntelliJ Terminal, Git Bash
PowerShell Windows에 들어 있는 터미널 프로그램. VS Code 터미널을 열면 기본으로 이것이 뜬다 PS D:\workspace>
경로 (path) 파일이나 폴더가 있는 곳을 적은 글자 D:\workspace\board-api
PATH 환경 변수 "명령 이름을 치면 이 폴더들에서 프로그램을 찾아라"라는 목록. 설치 프로그램이 여기에 자기 폴더를 더해 주어서 node, java를 어디서나 칠 수 있다 C:\Program Files\nodejs
JAVA_HOME "JDK가 어디 있나"를 알려 주는 환경 변수. Gradle 같은 도구가 이것을 보고 Java를 찾는다 C:\Program Files\Eclipse Adoptium\jdk-21...
확장자 파일 이름 끝의 . 뒤 글자. 파일의 종류를 나타낸다. Windows는 기본으로 숨긴다 index.html의 html, .env

2. 도구 이름

용어 뜻 이 과정에서
VS Code 가벼운 코드 편집기. 확장으로 기능을 더한다 HTML · CSS · JS · React · Node 코드 (2~9 · 12 · 13장 …)
확장 (extension) VS Code에 기능을 더하는 추가 프로그램 Prettier, ESLint, Live Share, REST Client
Node.js 브라우저 밖에서 JavaScript를 실행하는 프로그램 5장 npm, 8장 Vite, 9 · 12장 서버
npm Node.js와 함께 설치되는 패키지 관리 도구. 남이 만든 코드를 받아 온다 npm install, npm run dev
JDK (Java Development Kit) Java로 개발할 때 필요한 도구 묶음(컴파일러 + 실행기) JDK 21, Eclipse Temurin
Eclipse Temurin 무료로 받을 수 있는 JDK 배포판 하나. Adoptium이라는 단체가 만든다 10장부터
IntelliJ IDEA Java · Spring 개발용 통합 개발 환경(IDE). 코드 쓰기 · 실행 · 디버깅을 한 창에서 10장부터
PostgreSQL 표에 데이터를 저장하는 DB 서버. 이 과정의 DB 9장부터
pgAdmin PostgreSQL의 표와 데이터를 화면으로 보고 SQL을 실행하는 프로그램 9 · 10장
Docker Desktop 컨테이너를 만들고 돌리는 Docker를 Windows에서 쓰게 해 주는 프로그램 14장부터
WSL 2 (Windows Subsystem for Linux) Windows 안에서 Linux를 돌리는 기능. Docker Desktop이 이 위에서 돈다 07절
가상화 (virtualization) 한 컴퓨터 안에 또 다른 컴퓨터(가상 머신)를 만드는 CPU 기능. WSL 2와 Docker에 필요하다 07절

핵심 정리

  • 설치 프로그램이 PATH에 자기 폴더를 더해 주기 때문에 node, java, docker를 어디서나 칠 수 있다. 설치 뒤에는 터미널을 새로 열어야 바뀐 PATH가 보인다.
  • JAVA_HOME은 JDK의 위치를 알려 주는 환경 변수이고, 확장자는 파일 종류를 나타내는 이름 끝 글자다.
  • VS Code · Node.js는 화면과 Node 서버, JDK · IntelliJ는 Spring, PostgreSQL · pgAdmin은 DB, Docker Desktop(WSL 2)은 14장부터의 컨테이너에 쓴다.

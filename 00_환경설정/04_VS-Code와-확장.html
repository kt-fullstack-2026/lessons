VS Code와 확장 설치

준비시간35분개념 지도04 VS Code

한 줄 요약

VS Code는 2장부터 HTML · CSS · JavaScript · React · Node 코드를 쓰는 편집기입니다. 설치 프로그램으로 설치하고, 처음 한 번 확장 몇 개를 더합니다. 이 절에서 설치하는 확장은 코드를 가지런히 정리해 주는 Prettier, 실수를 미리 알려 주는 ESLint, 그리고 온라인 수업에서 같은 코드를 함께 보고 고치는 Live Share입니다. 요청을 보내 보는 REST Client는 9장 07절에서 설치합니다.

설치 시점: 2장 첫 수업 전.

1. VS Code 설치

  1. code.visualstudio.com에서 Download for Windows를 누릅니다. VSCodeUserSetup-x64-….exe가 받아집니다.
  2. 받은 파일을 더블클릭합니다. 사용권 계약에 동의합니다를 고르고 다음을 누릅니다.
  3. 설치 위치와 시작 메뉴 폴더는 기본값 그대로 다음을 누릅니다.
  4. 추가 작업 선택 화면에서 아래처럼 체크하고 다음 → 설치를 누릅니다.
칸 (영어 화면이면 괄호 안) 고를 것 이유
바탕 화면에 바로 가기 만들기 (Create a desktop icon) 원하는 대로 —
'Code(으)로 열기' 작업을 Windows 탐색기 파일의 상황에 맞는 메뉴에 추가 (Add "Open with Code" action to Windows Explorer file context menu) 체크 파일을 오른쪽 클릭해 바로 연다
'Code(으)로 열기' 작업을 Windows 탐색기 디렉터리의 상황에 맞는 메뉴에 추가 (… directory context menu) 체크 폴더를 오른쪽 클릭해 프로젝트째로 연다

2. 확장 설치

VS Code 왼쪽 세로 막대의 Extensions(네모 네 개 모양, Ctrl + Shift + X)를 누르면 검색 칸이 나옵니다. 이름을 검색하고, 만든 사람을 확인한 뒤 Install을 누릅니다. 비슷한 이름의 다른 확장이 많으므로 만든 사람과 확장 ID를 꼭 봅니다.

확장 만든 사람 · 확장 ID 하는 일 처음 쓰는 곳
Prettier - Code formatter Prettier · esbenp.prettier-vscode 저장할 때 들여쓰기 · 따옴표 · 줄바꿈을 한 모양으로 맞춘다 2장부터
ESLint Microsoft · dbaeumer.vscode-eslint JavaScript 코드의 실수(안 쓰는 변수, == 등)에 물결 밑줄을 긋는다. 프로젝트에 ESLint 설정이 있을 때 돈다 8장 Vite 프로젝트부터
Live Share Microsoft · ms-vsliveshare.vsliveshare 내 VS Code 화면을 다른 사람과 실시간으로 공유하고, 같은 파일을 함께 고친다. 온라인 수업에서 강사가 학생 코드를 보거나 학생이 강사의 코드 세션에 들어갈 때 쓴다. 처음 쓸 때 GitHub 계정(1장 03절)으로 로그인한다 강사가 안내하는 수업 때. 지금은 설치만 한다
REST Client Huachao Mao · humao.rest-client .http 파일로 요청을 보낸다 9장 07절에서 설치한다. 미리 설치해도 된다

3. Prettier를 기본 정리 도구로 정하기

Prettier를 설치하기만 하면 쓰이지 않습니다. "정리할 때 Prettier를 써라"와 "저장할 때마다 정리하라"를 설정합니다.

  1. 메뉴 File → Preferences → Settings(Ctrl + ,)를 엽니다.
  2. 위 검색 칸에 default formatter를 칩니다. Editor: Default Formatter에서 Prettier - Code formatter를 고릅니다.
  3. 검색 칸에 format on save를 칩니다. Editor: Format On Save를 체크합니다.

이제 HTML · CSS · JS 파일을 Ctrl + S로 저장할 때마다 Prettier가 모양을 맞춥니다. 2장 05절의 Shift + Alt + F(코드 정렬)도 Prettier로 정리합니다.

저장했더니 코드 모양이 바뀌었다면 정상입니다. 들여쓰기가 2칸으로 바뀌거나, 작은따옴표가 큰따옴표로 바뀌는 것은 Prettier가 정리한 것입니다. 교안의 코드도 대부분 같은 모양(큰따옴표, 문장 끝 ;)입니다. 팀 프로젝트에서는 모두 같은 정리 도구를 쓰면 Git에서 "모양만 바뀐 줄"이 덜 생깁니다(1장 충돌).

4. 확인

  1. 파일 탐색기에서 D:\workspace 폴더를 오른쪽 클릭 → Code(으)로 열기(Open with Code)를 고릅니다. 처음이면 "이 폴더의 작성자를 신뢰합니까?"가 나오는데, 내가 만든 폴더이므로 Yes, I trust the authors를 누릅니다.
  2. 메뉴 Terminal → New Terminal(Ctrl + `)을 엽니다. 아래쪽에 PS D:\workspace>가 보이면 됩니다. 이것이 VS Code 터미널(PowerShell)입니다. 05절에서 여기에 첫 명령을 칩니다.
  3. 왼쪽 Extensions에서 Installed를 펼쳐 Prettier · ESLint · Live Share가 보이면 끝입니다.

5. Live Share 세션에 참여하기 — 온라인 수업 때

강사가 채팅으로 세션 링크(https://prod.liveshare.vsengsaas.visualstudio.com/join?...)를 보내면 아래 세 단계로 들어갑니다. 지금 해 볼 필요는 없고, 첫 온라인 수업 때 이 절을 펴 놓고 따라 합니다.

  1. VS Code 왼쪽 세로 막대의 Live Share 아이콘을 누르고 Session Details에서 Join Collaboration session을 고릅니다. (또는 Ctrl + Shift + P를 누르고 Live Share: Join Collaboration Session을 칩니다.)
  2. 위에 나온 입력 칸에 강사가 보낸 링크를 붙여 넣고 Enter를 누릅니다.
  3. 처음이면 GitHub 계정(1장 03절)으로 로그인하라는 브라우저 창이 열립니다. 로그인하고 VS Code로 돌아옵니다. 강사 화면의 파일이 내 VS Code에 열리면 성공입니다.

안 될 때

증상 해결
로그인 창이 뜨지 않는다 VS Code를 완전히 껐다 켜고 1부터 다시 한다
"링크가 만료되었다"는 안내가 나온다 세션을 연 사람이 다시 열어야 한다. 새 링크가 오면 2부터 다시 한다

핵심 정리

  • VS Code는 기본 User 설치로 설치하고, "Code(으)로 열기" 두 칸과 PATH 추가를 체크한다.
  • 확장은 만든 사람 · 확장 ID를 확인하고 설치한다. Prettier · ESLint · Live Share는 지금, REST Client는 9장에서.
  • Prettier는 Default Formatter로 고르고 Format On Save를 켠다.
  • Live Share는 온라인 수업에서 코드를 함께 보고 고칠 때 쓴다. 강사가 보낸 링크를 Join Collaboration session에 붙여 넣고, 처음 쓸 때 GitHub 계정으로 로그인한다.
  • 폴더를 오른쪽 클릭 → Code(으)로 열기, Ctrl + `로 터미널을 연다.

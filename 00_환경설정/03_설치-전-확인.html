0장. 환경설정 — 과정 전체 개발 도구 설치

설치 전 확인 — 확장자, 작업 폴더

준비시간10분개념 지도03 설치 전 확인

한 줄 요약

설치를 시작하기 전에 두 가지를 확인합니다. ① 파일 이름 끝의 확장자가 보이는가, ② 모든 프로젝트를 둘 D:\workspace 폴더가 있는가. 둘 다 몇 분이면 끝납니다. 이 확인을 건너뛰면 나중에 원인을 찾기 어려운 오류를 만납니다. 확장자가 숨겨져 있으면 .env 파일이 .env.txt로 만들어져 서버가 설정을 읽지 못하고, 경로에 한글이나 빈칸이 있으면 Gradle · Node 도구가 빌드 중에 멈춥니다. 지금 확인해 두면 이런 오류를 미리 막을 수 있습니다.

1. 파일 확장자 보이기

Windows는 기본으로 index.html을 index로만 보여 줍니다. 이 상태에서 .env 파일을 메모장으로 만들면 실제 이름이 .env.txt가 되어, 서버가 비밀번호를 못 읽는 일이 생깁니다(10장).

  1. 작업 표시줄에서 파일 탐색기를 엽니다.
  2. 위쪽 도구 모음의 보기 → 표시 → 파일 확장명을 눌러 체크합니다.
  3. 아무 폴더나 열어 파일 이름 끝에 .pdf, .png 같은 글자가 보이면 됩니다.

같은 메뉴의 숨긴 항목도 체크해 둡니다. 1장 .git, 10장 .env, 15장 .github처럼 .으로 시작하는 폴더와 파일을 볼 수 있습니다.

2. 작업 폴더 D:\workspace 만들기

이 과정의 모든 프로젝트는 D:\workspace 아래에 만듭니다. 교안에 나오는 경로(D:\workspace\web-basic, D:\workspace\board-api …)도 모두 이 폴더 기준입니다.

  1. 파일 탐색기 왼쪽에서 내 PC를 누르고 로컬 디스크 (D:)를 엽니다.
  2. 빈 곳을 오른쪽 클릭 → 새로 만들기 → 폴더를 고르고, 이름을 workspace로 짓습니다.
  3. 주소 표시줄을 눌렀을 때 D:\workspace가 보이면 됩니다.
지킬 것 이유
경로에 한글을 쓰지 않는다 (D:\공부\코딩 ✗) Gradle · Node 도구 일부가 한글 경로에서 오류를 내거나 글자가 깨진다
경로에 빈칸을 쓰지 않는다 (D:\my work ✗) 명령에 경로를 쓸 때마다 따옴표가 필요해지고, 빠뜨리면 다른 폴더로 읽힌다
OneDrive · 바탕 화면 · 다운로드 폴더에 두지 않는다 OneDrive가 node_modules의 파일 수만 개를 동기화하느라 느려지고, 파일이 잠겨 설치가 실패하기도 한다
프로젝트 이름은 영어 소문자와 - board-api, react-memo. 교안과 같은 이름이면 따라 하기 쉽다

D 드라이브가 없는 노트북: 내 PC에 로컬 디스크 (C:) 하나뿐이면 C:\workspace를 만듭니다. 교안의 D:\workspace는 모두 C:\workspace로 바꿔 읽습니다. 나머지는 같습니다.

Windows 사용자 이름이 한글이라면 — 나중에 문제가 생기면 이렇게 합니다. 사용자 폴더(C:\Users\홍길동)에 한글이 들어가면, 도구가 그 아래에 자동으로 만드는 저장소(Gradle은 C:\Users\<이름>\.gradle, npm은 %LocalAppData%\npm-cache)에서 드물게 오류가 납니다. 작업 폴더를 D:\workspace로 두는 것만으로 대부분 피할 수 있으므로 지금은 아무것도 하지 않습니다. 10장에서 Gradle이, 5 · 8장에서 npm install이 경로 때문에 실패하면 아래처럼 저장소 위치를 한글이 없는 경로로 옮깁니다.

  • Gradle: 환경 변수 GRADLE_USER_HOME을 D:\gradle-home으로 만듭니다. 설정 → 시스템 → 정보 → 고급 시스템 설정 → 환경 변수에서 사용자 변수에 새로 만들기로 추가하고, IntelliJ를 다시 켭니다. Gradle은 이 변수가 있으면 캐시와 설정을 그 폴더에 둡니다.
  • npm: VS Code 터미널에서 npm config set cache D:\npm-cache를 한 번 칩니다. 이후 npm은 받은 패키지를 그 폴더에 보관합니다.
  • 그래도 안 되면 영어 이름의 Windows 로컬 계정을 새로 만들어 그 계정으로 수업을 듣는 방법이 있습니다. 설정이 모두 새로 시작되므로 위 두 가지가 모두 안 될 때 마지막 수단으로만 합니다.

출처: Gradle 문서 — Gradle User Home(GRADLE_USER_HOME), npm 문서 — config cache, npm 문서 — npm config set

핵심 정리

  • 파일 탐색기에서 파일 확장명과 숨긴 항목을 보이게 한다. .env가 .env.txt가 되는 것을 막는다.
  • 모든 프로젝트는 한글 · 빈칸 없는 D:\workspace 아래에 만든다. D 드라이브가 없으면 C:\workspace.
  • 사용자 이름이 한글이라 Gradle · npm이 실패하면 GRADLE_USER_HOME · npm config set cache로 저장소를 옮긴다.

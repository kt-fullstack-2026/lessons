2장. 웹의 동작 원리와 개발 도구

정리와 체크리스트

1단계 핵심시간20분개념 지도전체 흐름

2장에서 배운 것

  • 웹의 흐름 — 브라우저가 DNS로 IP를 찾고, 서버에 HTTP 요청을 보내고, 응답을 받아 화면을 그린다.
  • URL — 스킴 + 도메인 + (포트) + 경로 + (쿼리) + (프래그먼트). localhost는 내 PC.
  • HTTP — 요청은 메서드 + 경로 + 헤더 + 본문, 응답은 상태 코드 + 헤더 + 본문. 기억하지 않는다(무상태).
  • 상태 코드 — 2xx 성공, 4xx 요청 쪽 문제, 5xx 서버 쪽 문제.
  • VS Code — HTML 파일을 만든다. 저장 → 새로고침으로 바뀐 화면을 본다.

한눈에 보는 핵심

웹 = 요청과 응답

4xx는 요청을, 5xx는 서버를 먼저 의심한다

자주 쓰는 것 한 장 요약

체크리스트

말로 설명할 수 있으면 통과입니다. 오늘 퀴즈는 이 목록에서 나옵니다.

  • [ ] 주소창에 URL을 치고 화면이 나오기까지 네 단계를 1절 그림으로 설명할 수 있다.
  • [ ] URL을 보고 스킴 · 도메인 · 포트 · 경로 · 쿼리를 나눌 수 있다.
  • [ ] localhost:8080이 무엇을 가리키는지 말할 수 있다.
  • [ ] HTTP 요청과 응답이 각각 무엇으로 이루어지는지 말할 수 있다.
  • [ ] GET과 POST의 차이를 게시판 예로 말할 수 있다.
  • [ ] 200 · 404 · 500의 뜻을 말할 수 있다.
  • [ ] VS Code로 HTML 파일을 만들어 브라우저로 열 수 있다.
  • [ ] HTTP 응답 메시지에서 상태 코드와 본문을 찾을 수 있다.

2장. 웹의 동작 원리와 개발 도구

따라하기 — VS Code 기본 조작과 첫 HTML 파일

1단계 핵심시간1시간개념 지도VS Code — HTML 파일을 만드는 에디터

목표

VS Code로 HTML 파일을 하나 만들고 브라우저로 엽니다. 파일을 고치고 저장한 뒤 새로고침해서 바뀐 화면을 확인합니다.

1. 자주 쓰는 단축키

단축키 하는 일
Ctrl + S 저장
Ctrl + P 파일 이름으로 빨리 열기
Ctrl + Shift + P 명령 팔레트 (모든 기능 검색)
Shift + Alt + F 코드 정렬(포맷)
Ctrl + / 주석 넣기 · 빼기
Alt + ↑ / ↓ 지금 줄을 위 · 아래로 옮기기

출처: VS Code 단축키 (Windows, PDF)

2. 첫 HTML 파일 만들기

Windows 탐색기에서 D:\workspace\web-basic 폴더를 만들고, VS Code 메뉴 File → Open Folder로 이 폴더를 엽니다. 왼쪽 탐색기의 새 파일 버튼으로 index.html을 만들고, 편집기에서 !를 입력한 뒤 Enter(또는 Tab)를 누릅니다. HTML 기본 틀이 한 번에 채워집니다. 이 기능을 Emmet이라고 합니다.

lang="en"을 lang="ko"로 바꾸고, <title>과 <body> 안을 아래처럼 고칩니다.

<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>나의 첫 웹 페이지</title>
</head>
<body>
    <h1>안녕하세요, 나학생입니다</h1>
    <p>풀스택 개발자가 되려고 공부하고 있습니다.</p>
</body>
</html>

Ctrl + S로 저장합니다. 태그 하나하나의 뜻은 3장에서 배웁니다. 지금은 <h1>이 큰 제목, <p>가 문단이라는 것만 알면 됩니다.

3. 브라우저로 열기

VS Code 탐색기에서 index.html을 오른쪽 클릭 → Reveal in File Explorer(파일 탐색기에 표시)를 누릅니다. Windows 탐색기가 열리면 index.html을 더블클릭합니다. 기본 브라우저에 페이지가 열립니다.

주소창에는 아래와 비슷한 주소가 보입니다.

file:///D:/workspace/web-basic/index.html
부분 뜻
file 스킴. 인터넷이 아니라 내 PC의 파일을 직접 읽었다
/D:/workspace/web-basic/index.html 파일의 위치(경로)

file://로 연 페이지는 서버를 거치지 않습니다. 브라우저가 내 PC의 파일을 직접 읽었으므로, 1절 그림의 요청 · 응답이 없습니다. HTML · CSS 연습에는 이것으로 충분합니다. 서버와 주고받는 실습은 9장에서 Node.js 서버를 직접 만들면서 합니다.

4. 고치고, 저장하고, 새로고침

VS Code와 브라우저를 나란히 놓습니다. <p> 아래에 한 줄을 추가합니다.

    <p>오늘 배운 것: 요청과 응답</p>
  1. VS Code에서 Ctrl + S로 저장합니다.
  2. 브라우저에서 F5로 새로고침합니다.

새 줄이 보이면 성공입니다.

화면이 안 바뀌면 ① 저장했는지(탭 이름 옆에 ● 표시가 있으면 저장 안 됨) ② 새로고침했는지 확인합니다. 저장을 자주 잊는다면 VS Code 메뉴 File → Auto Save를 켭니다.

핵심 정리

  • ! + Enter로 HTML 기본 틀을 만든다.
  • 파일을 더블클릭하면 브라우저가 file://로 연다.
  • 고친 뒤에는 저장(Ctrl + S) → 새로고침(F5).
